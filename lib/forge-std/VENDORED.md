# Vendored test dependency

This directory contains the unmodified `src/` directory and both license files
from foundry-rs/forge-std release **v1.9.7**. It is an ordinary source dependency,
not a git submodule. Production contracts do not import it.

Archive: https://codeload.github.com/foundry-rs/forge-std/tar.gz/refs/tags/v1.9.7

Archive SHA-256:
`45157353ab49eab01d294565866731e599b32401757229689ee459aa26b7ee94`

No package download is required to build or test this project. Foundry and the
pinned Solidity compiler are supplied by the execution environment.
